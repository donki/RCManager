## Description

```
sOC Remote Connections Manager keeps your server connections and opens them in tabs: Remote Desktop
(RDP), SSH terminal, files over SFTP/SCP and FTP/FTPS. All in one window, organised in folders.

A tree of connections with nested folders and search; every session opens in its own tab and can go
full screen. Double-click to connect, or drag the connection onto the tab area.

REMOTE DESKTOP (RDP)
• The same Remote Desktop control that ships with Windows, with all its options in the same tabs as
  mstsc: display, local resources, experience and advanced (certificate, admin session, Remote
  Desktop Gateway).
• The desktop fits the tab (dynamic resolution) or uses a fixed size.
• Clipboard with text, images and files; your PC's drives inside the remote desktop to copy and
  move files with Explorer; printers, audio, microphone, smart cards.

SSH TERMINAL
• Built-in terminal with 16 and 256 colours, scroll regions, alternate screen (vim, htop), history,
  copy and paste. Password or private key (OpenSSH/PEM).

FILES: SFTP/SCP AND FTP/FTPS
• Two-pane browser, this PC on the left and the server on the right: upload and download files and
  whole folders by dragging or with F5, with a queue, progress and cancel.
• New folder, rename, delete; on Linux servers, permissions (chmod) and owner (chown).
• Explicit or implicit FTPS.

YOUR CONNECTIONS, WHERE YOU WANT THEM
• On this PC, or in your Google Drive or OneDrive so they follow you to every machine: they go to
  the app's private folder, encrypted with a passphrase only you know (AES-256). Passwords stored
  on the PC are protected with Windows data protection.
• Import your connections from Remote Desktop Manager (.rdm), keeping their folders.

No account, no ads, no trackers. Free software under the MIT licence. English and Spanish, light
and dark mode.
```

## Software dependencies (policy 10.2.4.1)

Nothing non-integrated to disclose: Remote Desktop uses the control that ships with Windows
(`mstscax`); SSH and file transfers use libraries bundled in the package (SSH.NET and FluentFTP,
MIT).

"sOC Remote Connections Manager collects no data. Connections are stored on the PC or, if the user

server of its own and sends nothing to third parties."
